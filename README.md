# Synchrotron storage as a dynamical system

Interactive companion widget to

> E. X. Miqueles, *Managing synchrotron data storage as a dynamical system*,

The widget implements the stock-and-flow model of the synchrotron share of
Ibirá, the central storage of Sirius (CNPEM, Brazil), and compares the
evolution of the disk with and without a usage rule (retention, quotas on
processed data, tape archiving).

**Open it:** https://USER.github.io/REPO/

It is a single self-contained HTML file (`index.html`): no installation and no
external dependencies. It can also be downloaded and opened offline in any
browser.
